Features

Simple, secure, and fast.

🚀

One-click Sending

Instantly send the current tab's title and URL to any paired device. Works via the popup or right-click context menu.

🔒

Secure Pairing

Connect devices using a short-lived 6-digit code. All requests are signed with HMAC for security.

📥

Smart Inbox

Received links appear in your inbox. Mark them as read or open them instantly. Syncs across devices.

⚡️

Realtime Sync

Powered by Supabase Realtime for instant delivery. Falls back to smart polling if connection is lost.

How it works

From zero to sharing in seconds.

01

Install & Register

Add the extension to Chrome. It quietly registers your device ID and secret locally—no account creation needed.

02

Pair Devices

Generate a code on one device and enter it on another. This exchanges secrets so they can "trust" each other.

  • Codes expire in 5 minutes
  • One-time setup per pair
03

Drop Links

Click the extension icon or right-click any page to send. The recipient gets a notification immediately.

Privacy First

Your data stays yours.

Minimal Data

We only store what's needed to deliver the link: title, URL, and timestamps. No browsing history is tracked.

Local Storage

Device secrets and keys live in your browser's local storage. You have full control to clear them anytime.
