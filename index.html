Why LinkDrop

Fast, deliberate link handoff for teams and devices.

One-click sending

Right-click and pick a contact from the context menu, or use the popup to send the current tab title + URL instantly.

Pair with a 6-digit code

Create or accept a short-lived code to add a contact. Rename or hide contacts locally to keep menus tidy.

Inbox + notifications

Background worker polls on a timer, raises system notifications, and lets you open or mark messages right away.

Verified payloads

Every message carries an HMAC signature derived from the pair secret. Invalid payloads are ignored and logged.

Resilient syncing

Supabase Realtime pushes when enabled; inbox polling keeps you covered when clients are offline or the browser is closed.

Local-first settings

Device IDs, pair secrets, aliases, and inbox cache live in chrome.storage.local; there is no analytics layer.

How it works

From pairing to delivery, in seconds.

1) Register quietly

On first open, LinkDrop registers the device via Supabase Edge Functions and saves a device ID/secret locally.

Headers are signed with HMAC-SHA256 using the device secret for every API call.

2) Pair two sides

Generate a 6-digit code and share it. Accepting the code exchanges pair secrets so both ends can trust each link.

  • Contacts sync to the context menu and popup.
  • Aliases and hide/show flags stay on your machine.

3) Drop the link

Pick a contact and send. The recipient gets a notification; clicking opens the URL and records opened_at.

Realtime Supabase Realtime streams insert events.
Fallback Alarm-driven polling every minute (configurable).
Get started

Ready for GitHub Pages and manual installs.

Configure your backend

  • Deploy Supabase Edge Functions from supabase/functions (register_device, pair, link, inbox, etc.).
  • Set LINKDROP_SERVICE_ROLE_KEY secret and run the included SQL schema.
  • Enable Realtime for linkdrop_messages and linkdrop_pairs if you want push delivery.

Load the extension

  • Edit src/config.js to point EDGE_BASE_URL (and optional Realtime keys) at your Supabase project.
  • Chrome → Extensions → Developer mode → “Load unpacked” → choose the repository root.
  • Open the popup once to register your device automatically.

Everyday use

  • Use the context menu item “LinkDrop: Send Current Page” to pick recent contacts.
  • Manage contacts and inbox in the popup (rename, hide locally, mark read, delete cached items).
  • Notifications open links and report back with an /message/opened call.
Privacy first

Designed to keep link sharing minimal and auditable.

What’s stored locally

Device credentials, pair secrets, aliases, and the inbox cache live in chrome.storage.local. You can clear cached messages anytime.

What hits the backend

Only what’s needed to deliver links: device IDs, pair metadata, message title + URL, and delivery timestamps. API calls are signed with HMAC headers.

No analytics or ads

LinkDrop runs without trackers. The only external service is your configured Supabase endpoint listed in the extension permissions.
